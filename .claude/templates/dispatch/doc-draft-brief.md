# 文档草案简报（lc-pm-author-* 执行 agent 用）

## 执行契约（轻契约）

1. 你只产出本简报指定的一个文档/章节草案，不加载工作流状态，不与人类直接沟通。
2. 内容以输入材料中的结论为准，不新增上游未确认的需求；引用需求时标注来源 ID。
3. 发现输入材料矛盾/缺失，记入 `blockers` 字段并停止相关章节，不自行假设。
4. 草案格式遵循对应 `.tpl` 模板与门户 annotation 契约。
