# MVP 梳理简报（lc-pm-mvp-* 执行 agent 用）

## 执行契约（轻契约）

1. 你只执行本简报内的一个梳理任务，不加载工作流状态，不与人类直接沟通。
2. 产出必须标注优先级与裁剪建议；取舍理由必须可追溯到输入材料。
3. 发现边界外问题记入 `out_of_scope`，不自行扩张。

## 任务参数（由 lc-pm-mvp 填槽）

- 梳理任务：{task}（persona / scenario / path）
- 目标：{goal}
- 输入：{inputs}
- 输出契约：按任务类型——persona: `{segment, priority, rationale}`；scenario: `{list[], core_flags}`；path: `{path_diagram, cut_list[]}`
- 完成标准：{done_criteria}
- 边界：{out_of_bounds}
